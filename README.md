# Docker (docker)

Docker is a platform for developers and sysadmins to build, share, and run applications in containers, packaging code and dependencies together for consistent deployment across environments.

## APIs

### Docker

Docker is a platform that lets developers package applications and all their dependencies into standardized units called containers. These containers bundle everything needed to run the software—code, runtime, system tools, and libraries—so the application runs consistently across different computing environments.
