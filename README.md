## APIs

### Docker
Docker is a platform that lets developers package applications and all their dependencies into standardized units called containers. These containers bundle everything needed to run the software—code, runtime, system tools, and libraries—so the application runs consistently across different computing environments, whether that's your laptop, a test server, or a production cloud system.
